Spesifikasi 4 Metode Pembayaran di Aplikasi
POST /api/transaksi/save_trx

1. Pembayaran Tunai (Cash)

Parameter API: tipe: 1 (Retail) | pembayaran: 1 (Cash) | pembayaran_grosir: 0

  • Input Kasir: Menggunakan react-native-currency-input untuk menginput nominal uang tunai yang diterima (total_bayar).
  • Validasi: total_bayar >= total_harga (Uang diterima tidak boleh kurang dari total tagihan bersih).
  • Perhitungan Kembalian: kembalian = total_bayar - total_harga.
  • Status Transaksi: Otomatis di-set Status: 2 (Lunas).

2. Pembayaran Transfer Bank (Manual)

Parameter API: tipe: 1 | pembayaran: 2 (Transfer) | pembayaran_grosir: 0

  • Input Form: Bank Tujuan (BCA, Mandiri, BRI, BNI), Nomor Rekening, Atas Nama Pengirim.
  • Upload Bukti Bayar: Menggunakan react-native-image-crop-picker (kamera/galeri). Dikirim sebagai binary file di FormData key bukti_bayar.
  • JSON Data Transfer: Data bank dibungkus jadi JSON string: {"bank":"BCA","no_rekening":"123","atas_nama":"Budi"}.
  • Status Transaksi: Otomatis di-set Status: 2 (Lunas).

3. Pembayaran Piutang / Jatuh Tempo (Grosir)

Parameter API: tipe: 2 (Grosir) | pembayaran_grosir: 3 (Piutang)

  • Pilihan Skema (Dropdown):
    • DP (Uang Muka): Input nominal DP (total_bayar < total_harga).
    • Non DP: Tanpa uang muka (total_bayar = 0).
  • Metode DP: Cash atau Transfer (jika transfer, wajib upload bukti transfer DP).
  • Jatuh Tempo: Menggunakan @react-native-community/datetimepicker untuk memilih tanggal jatuh tempo (format YYYY-MM-DD).
  • Status Transaksi: Di-set Status: 1 (Belum Lunas). Sisa tagihan: total_harga - total_bayar.

4. Pembayaran Keep (Barang Ditahan)

Parameter API: tipe: 2 (Grosir) | pembayaran_grosir: 4 (Keep)

  • Pilihan Skema:
    • Bayar Sekarang: Input nominal pembayaran saat ini.
    • Bayar Nanti: total_bayar = 0.
  • Fungsi Bisnis: Pelanggan grosir memesan dan menahan stok barang, namun pelunasan dilakukan saat pengambilan.
  • Status Transaksi: Di-set Status: 1 (Belum Lunas).

Detail Lengkap Modul Invoicing & Printing
Library: RNHTMLtoPDF, RNFetchBlob, ESC/POS

Di aplikasi Android, pencetakan invoice dan struk terbagi menjadi 2 jalur utama:

A. Jalur Generate PDF Invoice (GenerateScreen.jsx)

Library yang digunakan:

  • react-native-html-to-pdf → Mengonversi template HTML string ke format file PDF.
  • rn-fetch-blob → Mengakses filesystem Android dan menulis file PDF ke storage lokal.

Alur Pembuatan File PDF:

  1. Sistem memanggil GET /api/transaksi/detail?id={trx_id} untuk mengambil list produk, subtotal, diskon, dan total bayar.
  2. Menyusun HTML string dengan logo toko base64 (data_user.image_base64), Kop Toko, Tabel Item Belanja, dan Rincian Pembayaran.
  3. RNHTMLtoPDF.convert({ html, fileName, directory: 'Invoices', base64: true }).
  4. RNFetchBlob.fs.mkdir(DownloadDir + '/Invoices').
  5. RNFetchBlob.fs.writeFile(filePath, file.base64, 'base64') → Tersimpan di folder /Download/Invoices/mota_{kode_invoice}.pdf.

B. Jalur Cetak Struk Thermal Bluetooth (SamplePrint.jsx)

Library yang digunakan:

  • react-native-bluetooth-escpos-printer (ESC/POS via Bluetooth Classic SPP).
  • react-native-thermal-receipt-printer (Thermal BLE & WiFi Port 9100).
  • react-native-sunmi-v2-printer (Built-in hardware printer Sunmi).

Urutan Perintah Cetak Byte ESC/POS:

  1. BluetoothManager.connect(device.address) → Pairing via MAC Address Bluetooth.
  2. printPic(image_base64, { width: 250, left: 150 }) → Cetak raster image logo toko.
  3. printerAlign(ALIGN.CENTER) → Cetak Nama Toko, Alamat, No HP.
  4. printText('====================') → Garis pembatas.
  5. printColumn([4, 14, 10, 20], [L, C, R, R], ['Qty', 'Produk', 'Harga', 'Total']) → Loop belanjaan.
  6. printColumn([24, 24], [L, R], ['Subtotal', Rp]), Diskon, Total, Total Bayar, Kembalian.
  7. printColumn([24, 24], [L, R], ['Status Pembayaran', 'Cash - Lunas']).
  8. printText('\r\n\r\n\r\n') → Feed paper roll keluar.

5 Rumus Kalkulasi Bisnis Kasir
Business Logic Validation
1. Subtotal Keranjang Belanja
Subtotal = Σ (harga_aktual × qty)

Kasir dapat mengubah harga_aktual per item langsung di modal keranjang (misal memberi harga diskon khusus pelanggan loyal).

2. Total Tagihan Bersih (Diskon Ganda)
Total Tagihan = Subtotal − (Σ diskon_item + diskon_nota)

Mendukung 2 level diskon: diskon pada produk tertentu + diskon global pada nota belanja.

3. Uang Kembalian Tunai (Cash)
Kembalian = total_bayar − Total Tagihan (Syarat: total_bayar ≥ Total Tagihan)

Jika pembayaran Tunai, nominal uang kasir tidak boleh kurang dari total tagihan bersih.

4. Sisa Tagihan Piutang / Keep Grosir
Sisa Tagihan = Total Tagihan − (DP + Σ Cicilan yang Sudah Dibayar)

Jika hasil Sisa Tagihan == 0, backend secara otomatis mengubah status transaksi menjadi Status: 2 (Lunas).

5. Kas Akhir Shift Harian (Closing Dana)
Kas Akhir = Kas Awal + Omset Harian (Retail + Keep + Pelunasan) − Σ Pengeluaran Toko

Formula rekonsiliasi kas fisik di laci kasir saat pergantian shift / tutup toko harian.
