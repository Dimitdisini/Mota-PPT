## 🚀 Cara Menjalankan & Membuka Dokumen Interaktif

Dokumen presentasi (`.html`) dibuat secara mandiri (*standalone*) menggunakan Tailwind CSS via CDN dan FontAwesome tanpa memerlukan build step atau node server:

1. **Buka Langsung di Browser:**  
   Cukup klik dua kali (*double click*) file **`Penawaran_Mota_PPT.html`** atau **`Penawaran_Mota_v1.html`** untuk membukanya di Google Chrome, Safari, atau browser pilihan Anda.
2. **Navigasi Slide Deck (`Penawaran_Mota_PPT.html`):**
   - **Panah Kanan / Spasi:** Pindah ke slide berikutnya.
   - **Panah Kiri:** Kembali ke slide sebelumnya.
   - **Tombol Navigasi Bawah:** Klik tombol *Previous* / *Next* atau klik langsung nomor slide pada timeline bawah.
   - **Tombol Fullscreen:** Tersedia tombol layar penuh di kanan atas untuk pengalaman presentasi profesional.
